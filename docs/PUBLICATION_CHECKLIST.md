# Independent Publication Checklist

## Done Before Public Release

- Build the PDF from `paper/main.tex`.
- Run the test suite.
- Confirm the manuscript uses the public author name.
- Confirm `.gitignore` excludes generated pilot logs and downloaded third-party benchmark archives.
- Commit the publication package.
- Push a public GitHub repository.
- Create a `v0.1-preprint` GitHub release.

## OSF Preprint

Use `docs/OSF_PREPRINT_METADATA.md`.

Upload:

- `paper/build/main.pdf`

After GitHub/Zenodo publication, add:

- GitHub repository URL.
- Zenodo DOI.

## Zenodo
